## Implemented boundaries

Existing EPIC-38 knowledge/settings/files checks now recurse through subpackages
and share a small AST import resolver. It recognizes relative imports, deferred
function imports and `from package import child` aliases. Exact module-prefix
matching avoids accidental bans on similarly named sibling modules.

Additional deterministic checks protect the common leaf, neutral database/query
mechanics and injected Agent/retrieval paths. Named assembly roots have explicit
allowlists: database initialization and model registration, named Agent chat
reader/factory symbols, and the agent-definition deletion revocation call. Broad
model-registry imports cannot hide domain policy in shared query helpers.
Retrieval can share the extraction-status enum, but cannot acquire database,
configuration, chat/project/file or knowledge runtime/query dependencies.
Owning domain readers remain in their current modules; no domain framework or
new adapter was added. Synthetic violations and positive exception cases test
nested/deferred imports, package aliases, wildcard ORM imports and exact prefixes.

## Supported startup enforcement

Package `dev:raw`/`start`, root mprocs development and container startup use
`asterism.serve`. It rejects worker environment overrides unless unset or exactly
`1`, rejects CLI counts other than one and calls Uvicorn with `workers=1`.
`--check` validates without importing application configuration or opening data.
The real container entrypoint calls it before secrets, migrations or storage.
Host/port/proxy behavior and the previous development/production graceful timeout
settings are preserved. The full-image smoke script recognizes the new Python
module process when testing backend-failure supervision.

The new `pnpm test:container-launch` command uses the project's Python via uv,
builds a small Linux fixture with the actual launcher and entrypoint and locked
Uvicorn, and runs ten checks. Default/explicit one-worker modes pass; invalid
worker settings fail before secrets/application work and do not echo supplied
values. CI's quality job now runs this command. The fixture removes its own image
tag and containers, uses no user volume or account, and complements the full
application smoke test rather than replacing it.
