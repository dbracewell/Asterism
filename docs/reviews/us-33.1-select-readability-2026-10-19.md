# US-33.1 select-readability follow-up — 2026-10-19

The reported chat-model select contained its selected label but inherited
`text-primary-foreground` from the actual `AnimatedBorder` new-chat panel. Its
own background used `background`, so dark primary text could disappear on the
dark control. The previous neutral-card review did not exercise this inheritance.

`SelectTrigger` now explicitly pairs `bg-background` with `text-foreground`.
Placeholder colors retain their separate muted role. This shared fix applies to
selects in colored containers without changing model selection or catalog behavior.

The palette fixture now includes the real `ChatModelPicker` inside the same
`AnimatedBorder` component and checks its loaded selection, hover, focused popup
option and changed selection. Model responses are synthetic, intercepted in the
browser; no live model or settings changes are made.
