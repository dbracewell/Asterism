## Changes

- General has an expandable five-chat list independent of the current project.
  Existing individual and bulk chat actions are retained, with no duplicate
  General section. Project chats retain their separate scoped section.
- Sidebar project-open preferences are read with server-side `cookies()` and
  passed as initial props. Client rendering no longer reads browser cookies to
  initialize Projects. Removed the collapsible group's hydration suppression.
- Projects uses `PROJECTS_OPEN_COOKIE` (`asterism-projects-open`).
  `DashboardLayout` reads it beside the sessions cookie and passes the value
  through `AppSidebar` to `NavWorkspaces`; interaction writes use the same
  constant. The browser regression fixture also imports the shared constant.
- Collapsed content hides empty-state text and nested controls. List pagination
  disables controls while fetching and recovers when deletions remove a page.
- Updated the frontend README and workspace architecture contract.
