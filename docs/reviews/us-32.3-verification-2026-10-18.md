## Result

Conversation history and composer are flow siblings. History owns vertical scrolling;
the composer is limited to 60% of the available chat height and scrolls its expanded
context, queued files, error messages, multiline input and footer controls. The fixed
150px tail reserve and absolute overlay are removed. The existing stream follow and
manual-scroll lock remain, and jump-to-latest sits outside the composer's inner
scroll area. Send/stop are fixed-size existing shadcn buttons rather than stretching
to a tall attachment list. New-chat composition retains normal workspace scrolling.

The shared renderer wraps long text, inline code, links and omitted-image labels.
Tables, code and generated KaTeX have local horizontal keyboard-scroll areas with
focus outlines. Unlabelled fences use plain text rather than automatic language detection.
Plain and highlighted code keep literal text, semantic `pre`/`code`
markup and a copy header outside the scrolling body. Math starts at its first term
so the left side is not clipped by centered overflow. File names, citations,
thinking/tool arguments, sub-agent activity and response/version actions fit their
owning pane. Markdown HTML/resource/URL/math security policy is unchanged.

Conversation loading and empty states are explicit. Initial query failures provide
retry; a failed refresh retains saved messages with a warning and retry. File scope
retains its existing fail-closed behavior during loading and refresh errors rather
than exposing cached scope links as authorized.

No backend, API schema, generated client, dependency or storage policy changed.
Tests use synthetic data and isolated storage; the working database was not reset.

semantic keyboard regions and math/table rendering. Existing adversarial renderer
coverage remains intact.

`chat-reachability.spec.ts` exercises the production ChatSession, Markdown renderer,
file context, citations, attachment controls, agent activity and websocket handling
in a test-profile-only harness. Its matrix covers 320×300, 390×800, 768×300,
1440×900 with a 640px pane, 1440×400 with a 320px pane, and 390×600 with 200% text.
Desktop sidebars/panels in this harness are explicitly synthetic constraints; existing
authenticated mobile-shell cases exercise the actual application sidebar.

Checks include real ArrowRight horizontal scrolling, focused-action hit testing,
long tokens/filenames/tool arguments, long tables/code/math, expanded saved context,
six queued attachments and an eight-line draft. Final response content/actions and
Send/Discard remain reachable without overlapping history. Streaming checks retain
manual history position, jump to the latest delta, stop generation and preserve the
draft. State cases cover pending/initial failure/empty/success/cached-refresh failure
and retry for conversation and file scope, including withheld cached scope links.
Screenshots are emitted under Playwright test results and were visually inspected
for 320px mobile and nested 640px desktop cases.

Physical device keyboards, screen readers, remote CI and deployment are not certified
by these local Chromium and synthetic viewport checks.
